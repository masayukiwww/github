# 航空券の最適化（現金・マイル・セパレート）

最終更新: 2026-09-29 ／ 計算ツール: `tools/flight-planner.html`
（公開版: https://claude.ai/artifact/CXsP3uiE6d8W2t9CXzrUU1 ）

## 使い方（毎回の流れ）

1. マイクに「◯月◯日〜◯日ごろ、◯◯から◯◯」と伝える
2. マイクが **安い出発日の候補・ルート案・途中観光地・マイルを使う場合の見積もり** を出す
3. Trip.com / Google フライトで、その候補日の実額を見る（大阪発・東京発の両方）
4. 実額をツールの「比較シート」に入れる → 実質総額の安い順に並ぶ
5. マイルを使う案が勝ったら「空席確認 → マリオットから移行 → 即発券」

## 除外ルール（常に適用）

- **米国経由は常に除外**（ESTA が取れないため）。乗継だけでも ESTA が要る
- カナダ経由も eTA が必要なので除外
- 南米へは 中東（ドーハ・ドバイ）／トルコ／エチオピア／欧州 経由で組む

## 安い日の選び方

- 曜日：**火・水出発が安い**、金・日が高い
- 繁忙期を外す：年末年始、旧正月（アジア発）、ブラジルのカーニバル、セマナサンタ（南米）、日本の3連休・春休み
- 出発地を変えて比べる：大阪（KIX）／東京（HND・NRT）／ソウル（ICN）。
  差額が「移動費＋前泊代」を超えるなら出発地を変える

## セパレート（別々に買う）の鉄則

- 長距離の本体は **1枚の通し券**、最後の短距離だけ別で買う形が事故が少ない
- 別切りの乗り継ぎは最低5〜6時間、長距離便の後なら **1泊**（＝そのまま途中観光になる）
- 荷物は乗継地で受け取り→預け直し。その国に入国するのでビザ要確認
- 前の便が遅れても補償なし。買い直しリスクを込みで比較する

## マリオット Bonvoy → マイル

| 項目 | 内容 |
|---|---|
| 基本レート | 3ポイント → 1マイル（ほぼ全社。Air New Zealand など例外あり） |
| ボーナス | **60,000ポイントごとに +5,000マイル** → 60,000pt = 25,000マイル |
| **ユナイテッドだけ特別** | 上乗せが **+10,000マイル**（他社の倍）→ **60,000pt = 30,000マイル** |
| 最適な移行単位 | 60,000pt の倍数 |
| 移行ボーナス時期 | 過去は **9〜11月**に多い（Aeroplan 平均+29%、最大+35%） |
| 所要日数 | 数日〜2週間（航空会社による） |
| 失効 | 24か月動きがないとポイント失効 |

**鉄則：先に移さない。** 空席を確認 → 移行 → すぐ発券。移したマイルは戻せない。

### 使う価値の判断

```
1マイルの価値（円）＝（現金運賃 − 特典でも払う税・燃油）÷ 必要マイル
```

- マリオットのポイントはホテルに使っても 1pt ≒ 0.8円前後
- 60,000pt→25,000マイルなので、**1マイル 2.0円以上**で使えないなら移さずホテルに使う
- ユナイテッド（60,000pt→30,000）なら **1.6円以上**で元が取れる
- 手持ちの ANA マイルは 1.5円以上なら使ってよい

### 移行先の選び方

| 目的 | 移行先 | 理由 |
|---|---|---|
| スターアライアンス（ANA・ターキッシュ・エチオピア・ルフトハンザ等） | **Aeroplan**（第一候補）／ ANA | Aeroplan は片道可・途中降機 +5,000・燃油をほぼ取らない。ANA は手持ちと合算できる |
| スター便を最小ポイントで | **United** | 移行が一番お得（30,000/60,000pt）、燃油なし。ただし必要マイルは変動制なので、同じ便を Aeroplan と比べる |
| ワンワールド（JAL・アメリカン・カタール等） | JAL ／ Avios（カタール・BA・イベリア） | JAL は2026年7月にマリオットと提携強化。Avios は燃油高めなので要比較 |

ANA は2025年6月24日から特典航空券の **片道発券が可能**（提携社便も）。世界一周特典は廃止。

## 2027年1〜3月　大阪 → アスンシオン（ASU）

### 出発日

- **狙い目：1/12〜2/2、2/24〜3/12 の火・水**
- 避ける：1/1〜1/4、**2/3〜2/10**（旧正月 2/6＋カーニバル 2/6〜9）、**3/19〜3/28**（春分連休＋セマナサンタ 3/21〜28）
- 帰り（南米発）も 2/6〜10 と 3/21〜28 は避ける

### ルート案（運賃は2026年9月時点の目安）

| 案 | 経路 | 途中観光 | 片道目安 | マイル |
|---|---|---|---|---|
| A 中東経由 | KIX→DOH→GRU（カタール）＋ GRU→ASU 別切り | ドーハ／サンパウロ1泊（→イグアスの滝も近い） | 15〜23万円 | Avios・JAL（燃油高め） |
| B トルコ経由 | KIX/HND→IST→GRU（ターキッシュ）＋ GRU→ASU 別切り。代替：NRT→ADD→GRU（エチオピア） | イスタンブール1〜2泊 | 16〜25万円 | **GRU までスター通し。United / Aeroplan / ANA で可** |
| C マドリード経由 | KIX→欧州→MAD→ASU（エア・ヨーロッパ直行） | マドリード2〜3泊 | 18〜28万円 | ターキッシュ区間はスター |
| D 東京発 | 大阪→東京（新幹線 約1.5万円）→各ルート | — | 差額次第 | — |

- **現金なら A、マイルなら B** が基本線
- マリオットで B を賄う場合：Aeroplan 85,000マイルなら **約210,000pt**、ユナイテッドで同じマイル数なら **180,000pt**。
  ユナイテッドの必要マイルが Aeroplan より 約1.2倍以内ならユナイテッドの方が安くつく
- 1〜3月の旅なので、**10〜11月に移行ボーナスが出たらそこで移す**のが最適

### 入国（リスク箇所）

- パラグアイは日本国籍なら観光90日までビザ不要。ただし入国時に **出国の航空券** を求められることがある。
  片道で入るなら、居住手続き中を示す書類か、安い出国便の予約を用意
- 居住・税務上の論点は `docs/paraguay-tax-residency.md` を参照（渡航日は cédula/RUC 取得の段取りと合わせる）
