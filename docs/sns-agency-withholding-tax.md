# SNS運用代行で、お客様に「著作権の源泉課税」をかけない方法

最終更新: 2026-09-14

**設問**: 海外法人・海外居住者である自分が、日本企業の SNS 運用代行をする。
このとき、お客様（日本の発注企業）に **20.42% の源泉徴収義務** が発生しないようにするには、
どう設計すればよいか。

関連資料: [`japan-tax-legal-compliance.md`](./japan-tax-legal-compliance.md)（設立後の税務・法務の全体像）

> **免責事項**
> 本書は公開情報を整理した参考資料であり、税務上の助言ではありません。
> 源泉徴収の要否を最終的に判断するのは**お客様（支払者）**であり、その責任もお客様にあります。
> 実行前に日本の税理士に確認してください。

---

## 0. 結論

**「作業場所を海外にする」では逃げられません。「契約の性質」を変えるしかありません。**

そのうえで、有効な打ち手は次の6つです。効果の大きい順です。

| # | 打ち手 | 効果 |
|---|---|---|
| **1** | **著作権が自社に発生しない業務設計にする**（表現の最終決定権をお客様に置く） | **根本解決**。譲渡する著作権が存在しない |
| **2** | **契約の目的を「役務の受託」にし、著作権の対価を明確に区分する**（所基通161-37） | 区分された使用料部分**以外**は使用料に該当しない |
| **3** | **価格を「工数×レート＋利潤」で説明できる形にする**（所基通161-36の考え方） | 成果連動型を避けることで使用料認定を遠ざける |
| **4** | **画像・動画などの制作物を切り離し、日本の制作パートナーにお客様が直接発注する** | 国内取引になり源泉徴収が発生しない |
| **5** | **文書で武装する**（契約書・請求書・お客様の経理向け説明メモ・補償条項） | 法律上正しくても、書面がないと実務では引かれる |
| **6** | **租税条約のある国に法人を置く**（ジョージア等） | 使用料が**免税**になり、制作物込みでもゼロにできる |

**1〜5は今の設計の中でできること。6は設計そのものを変えることです。**

## 1. なぜ源泉徴収されるのか — 逃げ道と、逃げられない道

### 1.1 根拠条文

**所得税法161条1項11号**

> **国内において業務を行う者から受ける**次に掲げる使用料又は対価で**当該業務に係るもの**
> イ 工業所有権その他の技術に関する権利、特別の技術による生産方式若しくはこれらに準ずるものの
>   使用料又はその譲渡による対価
> **ロ 著作権（出版権及び著作隣接権その他これに準ずるものを含む。）の使用料又はその譲渡による対価**
> ハ 機械、装置その他政令で定める用具の使用料

これに該当すると、支払者に **20.42%** の源泉徴収義務が生じます（所法212条1項・213条1項）。

### 1.2 見落とされがちな2つのポイント

**ポイント①: 「譲渡による対価」も入っている**

「ライセンスではなく著作権を譲渡するから使用料ではない」は**通用しません。**
11号ロは**使用料と譲渡対価の両方**を対象にしています。
業務委託契約の定番である「本件成果物の著作権は甲に譲渡する」という一文が、そのまま源泉徴収の
トリガーになり得ます。

**ポイント②: 判定基準は「債務者主義」— 作業場所は関係ない**

11号は「**国内において業務を行う者から受ける**」ものが対象です。
つまり**お客様が日本で事業をしている以上、自分がどこで作業していても国内源泉所得**です。

> **これが本件の核心です。**
> 「パラグアイで作業しているから日本は関係ない」は、**使用料については成り立ちません。**
> 場所で逃げられるのは6号（人的役務提供事業）だけで、11号は性質でしか逃げられません。

### 1.3 一方で、「場所」で勝てる論点もある（6号）

**所得税法161条1項6号**（人的役務の提供事業の対価）は、
「**国内において**人的役務の提供を主たる内容とする事業」が対象です（所令282条）。

所令282条3号には「**科学技術、経営管理その他これらに類する分野に関する専門的知識又は
特別の技能**を有する者の当該知識又は技能を活用して行う役務の提供を主たる内容とする事業」
が挙がっており、**SNS運用コンサルティングがここに読まれる可能性はゼロではありません。**

**しかし6号は「国内において」行われたものに限られます。**
→ **海外で作業している限り、6号は当たりません。**
→ 逆に、**日本に出張して対面で研修・ワークショップを行うと、その部分は6号に当たり得ます。**

### 1.4 整理

| 論点 | 逃げ方 |
|---|---|
| **11号ロ（著作権の使用料・譲渡対価）** | **場所では逃げられない。契約の性質を変える**（→ 第2〜5章） |
| **6号（人的役務提供事業）** | **場所で逃げられる。日本国内での作業を発生させない**（→ 第6章） |
| **PE（恒久的施設）** | 日本に拠点・常駐者・契約締結権限者を置かない（→ 第6章） |

## 2. 打ち手1 — そもそも著作権が自社に発生しない業務設計にする

### 2.1 発想の転換

**「著作権を渡す方法」を考えるのではなく、「渡すべき著作権を持たない」設計にします。**
譲渡する著作権が存在しなければ、使用料も譲渡対価も発生しません。

### 2.2 業務を分解して、著作物性で色分けする

| 業務 | 著作物性 | 源泉リスク | 扱い |
|---|---|---|---|
| アカウント戦略の立案、KPI設計 | **なし**（アイデア・方法論は著作物でない） | 低 | ⭕ 自社で持つ |
| 競合分析・市場調査 | 低（事実・データ） | 低 | ⭕ 自社で持つ |
| 投稿スケジュールの設計・管理 | **なし** | 低 | ⭕ 自社で持つ |
| 投稿の実行（アカウント操作） | **なし** | 低 | ⭕ 自社で持つ |
| コメント・DM対応、コミュニティ管理 | **なし** | 低 | ⭕ 自社で持つ |
| 効果測定・レポーティング | 低 | 低 | ⭕ 自社で持つ |
| ハッシュタグ選定、投稿時間の最適化 | **なし** | 低 | ⭕ 自社で持つ |
| 短文の投稿コピー | 低〜中 | **中** | ⚠️ 承認フローで処理（→ 2.3） |
| 長文コンテンツ、記事 | **高** | **高** | ⚠️ 区分するか切り離す |
| **画像・動画・イラストの制作** | **高** | **高** | ❌ **切り離す**（→ 第5章） |
| **ロゴ・キャラクター・テンプレート制作** | **高** | **高** | ❌ **切り離す** |

> **SNS運用代行の業務の大半は、そもそも著作物ではありません。**
> 「アイデア」「手順」「データ」「実行」に著作権は発生しません（著作権法2条1項1号は
> 「思想又は感情を**創作的に表現**したもの」を著作物とします）。
> **問題になるのは、実は画像・動画などのクリエイティブ制作だけです。**
> ここを切り離せば、大部分は解決します。

### 2.3 「承認フロー型」で、表現の最終決定権をお客様に置く

投稿コピーのような微妙な領域は、**誰が最終的な表現を決めたか**で著作者が変わります。

```
[危険な運用]
自社が完成品を作る → お客様はそのまま投稿
→ 表現を創作したのは自社 → 自社が著作者 → 譲渡が必要 → 使用料リスク

[安全な運用]
自社が複数案を提示 → お客様が選択・修正・加筆 → お客様が最終決定・承認
→ 最終的な表現を決定したのはお客様 → 共同著作 or お客様が著作者
→ 譲渡する著作権が（少なくとも全部は）存在しない
```

**実装**:
- 投稿案は**必ず複数案**を提示する（A案・B案・C案）
- お客様の承認なしに投稿しない（承認フローを契約に明記）
- **承認の記録を残す**（Slack、チャットワーク、スプレッドシートの承認欄）
- 契約書に「本件投稿の内容は、乙の提案に基づき**甲が最終的に決定する**」と書く

> この運用は、**税務上の防御になると同時に、炎上リスクの分散にもなります。**
> 「お客様が承認したもの以外は投稿していない」という記録は、二重に効きます。

## 3. 打ち手2 — 契約の目的を「役務の受託」にし、著作権の対価を明確に区分する

### 3.1 根拠通達（これが決定的）

**所得税基本通達161-37「使用料に含まれない費用」**

> 工業所有権等**又は著作権**の提供契約に基づき支払を受けるもののうち、当該契約の目的である
> 工業所有権等又は著作権の**使用料として支払を受ける金額と明確に区分されている**費用又は代金は、
> 法第161条第1項第11号イ**又はロ**に掲げる使用料に該当しない。

**この通達は「著作権（ロ）」を明示的に含んでいます。**
→ **使用料部分と明確に区分された金額は、使用料ではない。**
→ **逆に言えば、区分していなければ、月額フィー全額が使用料と見られるリスクがあります。**

### 3.2 2つの構成 — どちらを取るか

**【案A】著作権を譲渡しない構成（推奨）**

```
契約の目的:  SNSアカウント運用管理業務の受託（役務提供契約）
著作権:      乙（自社）に留保。甲（お客様）には、甲の事業における利用に必要な範囲で
             無償・非独占の利用を許諾（※対価を設定しない）
対価:        月額固定の業務委託料のみ
```

- **利用許諾に対価を設定しない**ので、源泉徴収の課税標準となる「使用料の支払」が存在しない
- 契約の目的が「著作権の提供」ではなく「役務の受託」であることを明確にする
- ⚠️ 弱点: お客様が「権利が手に入らない」と嫌がる場合がある。永続的・取消不能な利用許諾にすることで実用上はカバーできる

**【案B】著作権を譲渡し、その対価を明確に区分する構成**

```
契約の目的:  SNSアカウント運用管理業務の受託
対価:        (1) 運用管理業務の対価       月額 ◯◯◯,◯◯◯円  ← 使用料に該当しない
             (2) 成果物の著作権譲渡の対価  月額  ◯◯,◯◯◯円  ← 20.42% の源泉徴収対象
```

- 通達161-37により、**(1)は使用料に該当しません**
- 源泉徴収されるのは**(2)だけ**。制作物の比重が小さければ、影響は限定的
- ⚠️ 弱点: **(2)の金額が不合理に低いと否認されます。**実態に見合った配分が必要

### 3.3 どちらを選ぶかの判断

| | 案A（譲渡しない） | 案B（区分して譲渡） |
|---|---|---|
| 源泉徴収 | **ゼロ** | 譲渡対価部分のみ |
| お客様の納得感 | △（権利が手に入らない） | ⭕ |
| 税務上の説明のしやすさ | ⭕（対価が存在しない） | ⭕（通達161-37に明文の根拠） |
| 制作物が多い案件 | △ | ⭕ |

> **まず案Aで提案し、お客様が権利の帰属にこだわる場合に案Bへ切り替える**、という順序が実務的です。
> どちらにせよ、**「著作権はすべて甲に譲渡する」の一文だけ入れて、月額一本で請求する**のが
> 最悪のパターンです。それは「区分されていない」ので、全額が使用料と見られる余地を残します。

## 4. 打ち手3 — 価格の決め方で、使用料認定を遠ざける

### 4.1 根拠通達

**所得税基本通達161-36**（図面、人的役務等の提供の対価が使用料に該当するかどうかの判定）は、
次のいずれかに当たるものを**使用料**とし、それ以外を**物・人的役務の提供の対価**としています。

> (1) その対価の額が、提供等をした権利を**使用した回数、期間、生産高又はその使用による利益の額に
>     応じて算定される**もの
> (2) (1)のほか、その対価の額が、図面その他の物の作成又は人的役務の提供のために要した
>     **経費の額に通常の利潤の額を加算した金額**に相当する額を**超える**もの

※ この通達は条文上は11号イ（工業所有権等）について書かれていますが、
**「成果連動なら使用料、原価＋利潤なら役務提供の対価」という考え方**は、実務上の判断軸として
広く参照されています。

### 4.2 実務上の帰結

| 料金体系 | 評価 | 理由 |
|---|---|---|
| **月額固定フィー**（工数 × レート ＋ 利潤） | ⭕ **推奨** | 「経費＋通常の利潤」として説明できる |
| 稼働時間ベースの従量課金 | ⭕ | 同上 |
| 投稿本数 × 単価 | ⭕ | 作業量に連動＝役務の対価 |
| **フォロワー増加数 × 単価** | ❌ **危険** | 「使用による利益の額に応じて算定」に近づく |
| **売上の◯% のレベニューシェア** | ❌ **危険** | 同上。最も使用料に見えやすい |
| 成功報酬（KPI達成ボーナス） | ⚠️ | 部分的なら許容範囲だが、比重を抑える |

> **レベニューシェア型・成果連動型は避けてください。**
> 営業上は魅力的な提案ですが、**税務上は最も使用料に見えやすい料金体系**です。
> どうしても成果連動を入れるなら、**固定フィーを主、成果報酬を従**にし、
> 成果報酬は「業務の成果に対するインセンティブであり、著作物の利用に対する対価ではない」と
> 契約書に明記してください。

### 4.3 見積書に「工数根拠」を残す

月額フィーの内訳を、**工数ベース**で説明できる資料を作っておきます。

```
戦略設計・月次改善        8時間 × @15,000円 = 120,000円
投稿企画・原案作成       16時間 × @12,000円 = 192,000円
投稿実行・スケジュール管理 12時間 × @ 8,000円 =  96,000円
コミュニティ管理         20時間 × @ 8,000円 = 160,000円
効果測定・レポート        4時間 × @15,000円 =  60,000円
─────────────────────────────────────
合計                     60時間              = 628,000円
```

**これがあるだけで「経費＋通常の利潤」の立証が一気に楽になります。**
税務調査でお客様が説明を求められたときに渡せる資料でもあります。

## 5. 打ち手4 — クリエイティブ制作を切り離す

### 5.1 最も確実な方法

**画像・動画・イラスト・ロゴの制作は、日本国内の制作パートナーに、お客様が直接発注する。**

```
[危険な流れ]
お客様 ──業務委託料（制作込み）──> 自社（海外）──外注──> 制作者
        ↑ 制作物の著作権譲渡が含まれる → 20.42% の源泉徴収リスク

[安全な流れ]
お客様 ──運用管理フィー──────> 自社（海外）   ← 役務提供の対価。源泉なし
      └─制作費──────────> 日本の制作会社   ← 国内取引。源泉なし
                                 ↑ 自社はディレクションのみ（役務）
```

- 日本の居住者・内国法人への支払いなので、**源泉徴収の問題が発生しません**
- 自社は「制作のディレクション」という**役務**を提供するだけ
- お客様は制作物の著作権を、制作パートナーから直接取得できる（お客様にとっても分かりやすい）

### 5.2 副次的なメリット

- 制作パートナーへの外注費が自社の売上を経由しないので、**パラグアイ側の IRE 課税ベースも下がる**
- お客様が制作費を直接支払うので、**自社の資金繰りが軽くなる**
- 制作物の権利関係がシンプルになり、後々のトラブルが減る

### 5.3 それでも自社で制作する場合

- 第3章の**案B（区分）**を使い、制作物の著作権譲渡対価を明示的に切り出す
- 制作物1点ごとに単価を設定し、**制作納品書と運用レポートを別に発行する**
- 請求書も**2行に分ける**

## 6. あわせて潰しておく3つの論点

### 6.1 6号（人的役務提供事業）— 日本での作業を発生させない

- 契約書に「**本業務に係る役務は、すべて日本国外において提供される**」と明記
- 日本への出張を伴う対面研修・ワークショップ・撮影立会いは、**別契約・別請求**にする
  （その部分は6号に当たり得るので、源泉徴収を前提に見積もる）
- 出張がある月は、その事実が月額フィーに混入しないよう注意

### 6.2 PE（恒久的施設）— 日本に足跡を残さない

- ❌ 日本の住所を、請求書・契約書・ウェブサイトに使わない
- ❌ 日本在住者に、お客様との**契約締結・価格決定・条件交渉**を任せない
- ⭕ 日本在住の外注は、**成果物ベースの業務委託**に限る
- ⭕ 契約書の署名者は本人（海外所在）、署名日と署名地を記録

> PE認定されると、**お客様の源泉徴収の話どころではなく、自社が日本で法人税の
> 申告納税義務を負います。**しかも日パ間に条約がないので、二重課税の調整手段がありません。

### 6.3 消費税 — 「運用代行」と「広告配信」を混ぜない

| 業務 | 消費税の扱い |
|---|---|
| SNS運用代行（海外で作業する役務提供） | **国外取引 → 不課税**（消令6条2項：役務提供地基準） |
| **SNS広告の配信**を自社が請け負う | **電気通信利用役務の提供**に該当し得る → 事業者向けなら**リバースチャージ** |

広告配信を含む場合、利用規約・請求書に
「**本取引はリバースチャージ方式により、貴社に消費税の申告・納税義務が生じます**」
と表示する義務があります（消法62条）。→ [`japan-tax-legal-compliance.md` 第8章](./japan-tax-legal-compliance.md)

**広告出稿の代行は、運用代行とは別の契約にするのが安全です。**

## 7. 打ち手5 — 文書で武装する（実はここが一番重要）

### 7.1 なぜお客様は引きたがるのか

**法律上引く必要がなくても、お客様の経理は引きます。**理由は単純です。

| お客様の立場 | リスク |
|---|---|
| **引かずに払って、後で「引くべきだった」と指摘された** | **不納付加算税10%（自主納付なら5%）＋ 延滞税** を**お客様が負担**。しかも本税も一旦お客様が納付する |
| **引いて払った（本当は引く必要がなかった）** | **お客様には何のリスクもない**（損をするのは受取側だけ） |

> **お客様にとって、引くのはノーリスク、引かないのは片側リスクです。**
> だから何も説明しなければ、**必ず引かれます。**
> 「引かない」を選んでもらうには、**お客様が社内と税理士に説明できる材料を渡すしかありません。**

### 7.2 渡すべき4点セット

| # | 文書 | 目的 |
|---|---|---|
| 1 | **契約書の対価条項・源泉徴収条項** | 法的な裏づけ（→ `templates/sns-unyo-keiyaku-jokou.md`） |
| 2 | **請求書の記載** | 経理が処理する時点で目に入る |
| 3 | **お客様の経理・税理士向け説明メモ** | 社内決裁と税理士確認を通すための材料（→ `templates/gensen-chosyu-setsumei-memo.md`） |
| 4 | **補償条項（indemnity）** | 「万一の追徴は当方が負担する」→ お客様のリスクをゼロにする |

### 7.3 補償条項が効く理由

7.1 のとおり、お客様は「引かないリスク」だけを負っています。
**そのリスクを自社が引き受ければ、お客様は引かない判断ができます。**

```
甲が本契約に基づく支払について源泉徴収を行わなかったことにより、
甲が日本の税務当局から源泉所得税の納税を求められた場合、
乙は、当該本税、不納付加算税及び延滞税に相当する額を甲に補償する。
```

- **営業上、極めて強力**です。「税金の心配はこちらで持ちます」と言えます
- ⚠️ ただし**自社が実質的にリスクを負う**ことになります。
  1件あたりの金額と、自社の判断の確度を見て入れるかどうか決めてください
- 金額の大きい案件では、**補償額に上限（例：当該契約に基づき受領した額）** を設けるのが実務的

### 7.4 金額の大きい案件は、お客様に事前照会してもらう

年間数千万円規模の案件なら、**お客様から所轄税務署に文書で事前照会**してもらうのが最も確実です。
- お客様の税務署に対する照会なので、**お客様自身の安心材料**になる
- 回答が出れば、以後の年度も同じ整理で通せる
- 照会書のドラフトはこちらで用意して提供すると、話が早い

## 8. 打ち手6 — 根本解：租税条約のある国に法人を置く

ここまでの打ち手は「使用料に該当させない」ための工夫です。
**租税条約があれば、使用料に該当しても源泉税がゼロになります。**

| | パラグアイ法人 | ジョージア法人 |
|---|---|---|
| 日本との租税条約 | **なし** | **あり**（2021/7/23発効） |
| 著作権使用料の源泉税 | **20.42% 固定** | **免税**（特典制限条項の適格者要件あり） |
| 制作物の著作権を譲渡した場合 | 20.42% | **免税** |
| 必要な手続 | — | **「租税条約に関する届出書」を支払前にお客様経由で所轄税務署へ提出** |

> **ジョージア法人なら、著作権を丸ごと譲渡しても源泉税はゼロにできます。**
> 契約の作り込みで神経を使う必要がなくなり、お客様への説明も「条約で免税です、届出書はこちらです」
> の一言で済みます。**営業コストと税務リスクの両方が消えます。**
>
> ⚠️ **届出書の提出を忘れると、国内法の 20.42% で源泉徴収されます。**
> 契約開始時のチェックリストに入れてください。

これは `japan-tax-legal-compliance.md` 第6章で「設立地は税率ではなく条約で選ぶ」と書いた話の、
最も具体的な現れです。**日本企業を顧客にする限り、条約の有無が毎月の手取りに直結します。**

## 9. やってはいけない5つ

| # | やってはいけないこと | 何が起きるか |
|---|---|---|
| **1** | **「本件成果物の著作権はすべて甲に譲渡する」の一文だけ入れて、月額一本で請求する** | 区分がないので、**月額フィー全額**が使用料と見られるリスク（所基通161-37の反対解釈） |
| **2** | **レベニューシェア・フォロワー数連動の料金体系にする** | 「使用による利益の額に応じて算定」＝使用料の典型（所基通161-36(1)） |
| **3** | **日本に常駐スタッフを置く／日本で対面業務を継続的に行う** | 6号の人的役務提供事業＋**PE認定**。源泉徴収どころか法人税の申告義務 |
| **4** | **契約書・見積書・請求書・納品物の記載が食い違う** | 税務調査で「実態は著作物の提供」と再構成される |
| **5** | **お客様の経理に何も説明せず「源泉徴収しないでください」とだけ言う** | 通らない。経理は根拠のない依頼を受け入れられない。**必ず引かれる** |

## 10. 導入チェックリスト

### 10.1 契約を結ぶ前に

- [ ] 業務内容を**第2章の表**で色分けし、著作物性の高い業務を特定した
- [ ] クリエイティブ制作を**切り離せるか**検討した（→ 第5章）
- [ ] 料金体系を**固定フィー中心**にした（レベニューシェアを避けた）
- [ ] 月額フィーの**工数内訳**を作った（→ 4.3）
- [ ] 案A（譲渡しない）／案B（区分して譲渡）のどちらで行くか決めた（→ 3.3）

### 10.2 契約書に入れる条項

- [ ] 契約の目的が「**役務の受託**」であることの明記
- [ ] **役務は全て日本国外で提供される**ことの明記
- [ ] 投稿内容の**最終決定権は甲（お客様）にある**ことの明記（承認フロー）
- [ ] 著作権条項（案A：無償の利用許諾／案B：譲渡＋対価の明確な区分）
- [ ] 対価条項（案Bなら**2区分で金額を明示**）
- [ ] 源泉徴収に関する条項
- [ ] **補償条項**（入れるかどうかは案件規模で判断）
- [ ] アカウントの帰属・返還に関する条項

> そのまま使える条項案: **[`templates/sns-unyo-keiyaku-jokou.md`](./templates/sns-unyo-keiyaku-jokou.md)**

### 10.3 運用フェーズ

- [ ] 請求書を**役務提供の対価**として記載（案Bなら2行に分ける）
- [ ] 投稿案は**複数案提示 → お客様が選択・承認**の流れを維持
- [ ] **承認の記録**を残す（チャットのログ、承認シート）
- [ ] 日本出張が発生したら、**その部分を別契約・別請求**にする
- [ ] お客様の経理に**説明メモを渡す**（契約開始時に必ず）

> そのまま送れる説明メモ: **[`templates/gensen-chosyu-setsumei-memo.md`](./templates/gensen-chosyu-setsumei-memo.md)**

### 10.4 ジョージア法人にした場合の追加手続

- [ ] **「租税条約に関する届出書（様式3：使用料に対する所得税の軽減・免除）」**を作成
- [ ] **支払を受ける日の前日まで**に、お客様経由で所轄税務署へ提出
- [ ] 特典制限条項（LOB）の適格者要件を満たすことを確認
- [ ] 契約更新・条件変更のたびに、届出書の再提出要否を確認
