## 1. パラグアイの税率

根拠法: **Ley N° 6380/2019**（税制の近代化及び簡素化に関する法律）。
税務当局は **DNIT**（Dirección Nacional de Ingresos Tributarios、旧 SET）。

| 税目 | 略称 | 税率 | 備考 |
|---|---|---|---|
| 法人所得税 | **IRE** | **10%** | 純所得に対する単一税率。中南米で最低水準 |
| 個人所得税（役務提供所得） | **IRP-RSP** | **8 / 9 / 10%** | 下表参照。累進 |
| 個人所得税（資本所得・キャピタルゲイン） | **IRP-RGC** | **8%** | 一律 |
| 配当・利益分配税 | **IDU** | 居住者 **8%** / 非居住者 **15%** | 分配時に源泉。residents 分は再分配時に税額控除可 |
| 非居住者所得税 | **INR** | **15%** | 取引類型ごとの「みなし所得率」に 15% を乗じるため、実効税率はこれより低いことが多い |
| 付加価値税 | **IVA** | **10%**（標準）／ **5%**（軽減） | 軽減: 基礎食料品、医薬品、不動産賃貸等。輸出 0%（仕入税額還付あり） |
| 選択消費税 | **ISC** | 品目別 | 燃料・たばこ・酒類等 |
| 固定資産税（市税） | — | 課税評価額の概ね **1%** | 市（municipalidad）が賦課 |
| 相続税・贈与税 | — | **なし** | |
| 純資産税・富裕税 | — | **なし** | |
| 社会保険 | **IPS** | 被用者 **9%** / 雇用主 **16.5%** | 雇用関係がある場合 |

### IRP-RSP の累進ブラケット

| 年間課税所得（グアラニー = Gs） | 概算 USD | 税率 |
|---|---|---|
| 〜 50,000,000 Gs | 〜 約 $7,600 | **8%** |
| 50,000,001 〜 150,000,000 Gs | 約 $7,600 〜 $22,800 | **9%** |
| 150,000,001 Gs 〜 | 約 $22,800 〜 | **10%** |

USD 換算はレート変動により変わります。実費控除（家族の生活費、教育費、住宅取得等）が
広く認められる点が特徴で、実効負担はさらに下がることがあります。

## 2. 属地主義の原則と例外

パラグアイは **属地主義（territorial taxation）** を採用し、国外源泉所得は原則として課税されません。

**ただし「100% テリトリアルで海外所得は完全非課税」という説明は不正確です。**
Ley 6380 は以下を「パラグアイ源泉所得」とみなす規定を置いています。

- 国外の銀行・金融機関に預けた資本から生じる **利息・手数料・収益・キャピタルゲイン**
- **為替差益**
- **国外法人の社員・株主として得る配当・利益**
- 国外の者に対する融資・貸付から生じる利息等（貸手がパラグアイに設立／居住する場合）

いずれも「投資主体または受益者がパラグアイに設立され、または居住する場合」という条件付きです。
個人（IRP-RGC 8%）にどこまで及ぶかは実務上の論点であり、**現地会計士への個別確認が必須**です。

## 3. パラグアイ税務居住者になる手順と書類

### 3.1 在留資格（移民法 Ley 6984/2022）

2022年10月18日施行の新移民法により、原則 **2段階** になりました。

```
[標準ルート]  一時居住 residencia temporaria（2年） ─→ 永住 residencia permanente
[投資家ルート] SUACE 投資家許可 ─→ 永住を直接申請
               条件: 2年以内に USD 70,000 の投資 ＋ 5名以上の雇用創出
```

- 処理期間: おおむね **3〜4か月**。審査中のパラグアイ滞在は不要（受理証で足りる）。
- 一時居住から永住へ進むには、申請者が **1年以上国外に出ていない**ことが要件。
  1年以上出国していると一時居住の更新しかできず、永住に進めません。

**必要書類**（国外発行のものは **アポスティーユ** ＋ **パラグアイ登録の宣誓翻訳者によるスペイン語訳** が必須）

| 書類 | 日本での取得元 |
|---|---|
| パスポート（有効期間に余裕を） | 外務省／旅券事務所 |
| 出生証明書 | 戸籍謄本 → 出生事項を証明する形で作成・アポスティーユ |
| 婚姻証明 or 独身証明 | 市区町村／法務局 |
| **無犯罪証明書（警察証明）** | 都道府県警察本部（犯罪経歴証明書） |
| 健康診断書 | 現地または指定様式 |
| 経済的資力の証明（solvencia） | 残高証明、就業証明、事業・投資の証憑 |
| 入国記録・入国スタンプ | 出入国時 |

取得後に発行されるもの:
- **Cédula de Identidad para Extranjeros**（外国人身分証）
- residencia の **決議書（resolución）**

### 3.2 税務居住者としての登録・証明

1. **RUC**（Registro Único del Contribuyente、納税者番号）を DNIT に登録
2. **Certificado de Residencia Fiscal**（税務居住者証明書）を DNIT に申請
   - 根拠: **Resolución General N° 65/2020**
   - 要件: **年間120日以上の滞在**、または **生活上の利益の中心（centro de intereses vitales）**
     がパラグアイにあること（家族の住居、投資、事業活動など）
   - 添付書類:
     - 有効な cédula de identidad
     - RUC および納税の適正性（regularidad fiscal）
     - **移民局発行の出入国記録（constancia de movimiento migratorio）**
     - 賃貸借契約書
     - 公共料金の請求書
     - 子の在学証明（該当する場合）
   - 発行: 申請の翌日から **10営業日以内**
   - **年度ごとに取得**（毎年更新が必要）

### 3.3 日本との租税条約が「ない」ことの意味

**日本とパラグアイの間に租税条約（二重課税防止条約）は存在しません。**
（2025年12月5日に署名された日パ投資協定は投資保護の協定であり、税とは別物です。）

その帰結:

- 条約上の **タイブレーカー・ルール（双方居住者の振分け規定）が使えない**
- 両国が同時に「自国の居住者」と主張した場合、**調整する仕組みがない**（相互協議も不可）
- パラグアイの税務居住者証明書は、日本側では **条約適用の根拠ではなく、事実認定の一証拠**
- 日本の居住者判定は、日本の国内法だけで独立に行われる

→ **だからこそ、日本側の「生活の本拠」立証を証拠の厚みで固める必要があります。**

## 4. 日本の非居住者になるための手続きと立証書類

### 4.1 判定基準

- 根拠: **所得税法2条**、**所得税法施行令14条・15条**
- 「住所」＝ **生活の本拠**。住居・職業・資産の所在・家族の居住状況等の
  **客観的事実による総合判断**
- **武富士事件（最判 平成23年2月18日）** 以降、**実際の滞在日数などの客観的事実**が重視される
- 職業上、継続して1年以上国外に居住することを通常必要とする場合は **非居住者と推定**
- **日本に「183日ルール」は存在しません。住民票を抜いただけでは非居住者になりません。**

### 4.2 出国時に必ず踏む手続き（土台）

| # | 手続き | 提出先 | 備考 |
|---|---|---|---|
| 1 | **海外転出届** | 市区町村 | 後日 **住民票の除票（写し）** を取得・保管 |
| 2 | **所得税・消費税の納税管理人の届出書** | 所轄税務署 | 未提出のまま出国すると加算税・延滞税のリスク |
| 3 | **出国年の確定申告**（出国日までの所得） | 所轄税務署 | 給与所得者は **出国時年末調整** |
| 4 | **国外転出時課税（出国税）の判定・申告** | 所轄税務署 | 下記 4.3 |
| 5 | 健康保険・国民年金の **資格喪失手続** | 保険者／年金事務所 | 国民年金の任意加入は「日本に基盤あり」の材料になり得る |
| 6 | マイナンバーカードの海外継続利用 or 返納 | 市区町村 | |
| 7 | 出国後の日本源泉所得（不動産賃貸等）の申告 | 納税管理人経由 | |

前年の申告納税額が15万円（予定納税基準額）以上の場合、予定納税の取扱いにも注意。

### 4.3 国外転出時課税（出国税）

以下の **両方** に該当する個人が対象:

1. 出国時に所有する **有価証券等の価額の合計が 1億円以上**
2. 出国の日前10年以内に、国内に住所または居所を有していた期間の合計が **5年超**

→ 出国時に **含み益** に対して所得税が課されます（実際に売却していなくても課税）。

**納税猶予** の選択が可能:
- **納税管理人の届出** ＋ **担保の提供** が条件
- 猶予期間 **5年**（延長で最長 **10年**）
- 猶予期間中に譲渡した場合、または帰国した場合の取扱いに個別ルールあり

### 4.4 「生活の本拠はパラグアイ」を立証する証拠

強い順。**継続性と客観性**（第三者が発行し、日付が連続しているもの）が効きます。

#### ★★★ 最重要

- **滞在日数の客観記録**
  - パスポートの出入国スタンプ（全ページのコピーを毎年保管）
  - **出入国在留管理庁への保有個人情報開示請求**による日本の出入国記録
  - パラグアイ移民局発行の **movimiento migratorio**（出入国記録証明）
- **在留資格の証憑**
  - cédula de identidad（永住／一時居住）
  - residencia の決議書（resolución）
- **税務上の地位**
  - RUC 登録証
  - **DNIT の税務居住者証明書**（毎年取得）
  - パラグアイでの確定申告書・納税証明
- **住居の継続性**
  - 登録済みの賃貸借契約書、または不動産登記（matrícula）
  - **ANDE（電気）／ESSAP（水道）／通信** の **毎月の請求書と支払記録**
    ← 毎月連続していることが「実際に住んでいる」証拠として非常に強い

#### ★★ 補強

- **職業の所在**: パラグアイ法人の役員登記（acta / escritura）、雇用契約、給与明細、IPS 加入記録
- **家族の同行**: 配偶者・子の cédula、学校の在学証明
  ← **家族が日本に残ると大きく不利**。単身赴任的な形態は否認リスクが上がる
- **金融**: パラグアイ銀行口座の明細（日常の生活支出が現地で発生している記録）。
  日本のクレジットカード・電子マネー利用が日本に集中していないこと
- **日本側資産の整理**:
  - 自宅の **売却**、または第三者への **賃貸**（「いつでも戻れる住居」を残さない）
  - 自動車・駐車場・会員権の解約
  - 日本の携帯回線の解約

## 5. 落とし穴とリスク

| リスク | 内容 | 対応 |
|---|---|---|
| **住民票の誤解** | 転出届だけでは非居住者にならない。実態判定 | 生活実態そのものを移す |
| **日本法人の役員継続** | 役員報酬は **勤務地を問わず国内源泉所得**。非居住者でも **20.42% 源泉課税** | 役員退任、または課税を前提に設計 |
| **CFC税制（タックスヘイブン対策税制）** | パラグアイの法人税率10%は租税負担割合20%未満。日本居住中に現地法人を保有すると合算課税の対象になり得る | 法人設立と非居住者化の **順序** を税理士と設計 |
| **PE（恒久的施設）認定** | パラグアイから日本法人を実質的に経営 → 日本法人の課税は継続。逆にパラグアイ側で PE 認定の可能性 | 経営実態と法形式を整合させる |
| **CRS（共通報告基準）** | パラグアイは CRS 参加国。現地口座情報は居住地国へ自動報告される | 自己宣誓（self-certification）と実態を一致させる。虚偽申告は不可 |
| **出国税の申告漏れ** | 1億円要件の判定漏れ、納税管理人未届 | 出国前に必ず判定 |
| **一時帰国が多い** | 日本滞在日数が多いと否認リスク | 下記の安全側運用 |
| **二重居住** | 租税条約がないため調整不能 | 証拠の厚みで日本側の主張を封じる |

### 滞在日数の安全側の運用（目安）

```
パラグアイ滞在: 年 120 日以上（税務居住者証明書の要件）
日本滞在:       年 90 日以下（183日を大きく下回る水準に抑える）
```

日本の判定は日数だけで決まるものではありませんが、日数は最も反証しにくい客観的事実です。
毎年、搭乗券・宿泊記録・国境スタンプで裏付けたカレンダーを作成し保管してください。

## 6. チェックリスト

### 出国前

- [ ] 日本の国際税務に強い税理士に相談（出国税・CFC・役員報酬の設計）
- [ ] 有価証券等の残高を確認し、**国外転出時課税の対象か判定**
- [ ] 対象なら納税猶予の要否を判断（納税管理人＋担保）
- [ ] **納税管理人の届出書** を税務署へ提出
- [ ] 出国年の確定申告 or 出国時年末調整
- [ ] 日本法人の役員の地位をどうするか決定
- [ ] 日本の自宅の売却／賃貸の手配（「いつでも戻れる住居」を残さない）
- [ ] 車・駐車場・会員権・携帯回線の解約
- [ ] 健康保険・国民年金の資格喪失手続
- [ ] **海外転出届** を提出し、**住民票の除票** を取得
- [ ] マイナンバーカードの手続

### パラグアイ側（渡航前に準備）

- [ ] 無犯罪証明書（警察証明）＋アポスティーユ＋宣誓翻訳
- [ ] 出生証明・婚姻／独身証明＋アポスティーユ＋宣誓翻訳
- [ ] 経済的資力の証明
- [ ] 在留資格の申請（一時居住 or SUACE 投資家ルート）
- [ ] cédula de identidad の取得
- [ ] **RUC** の登録
- [ ] 住居の賃貸借契約（登録済みのもの）
- [ ] 公共料金（ANDE／ESSAP／通信）を **自分名義** で契約
- [ ] 現地銀行口座の開設

### 毎年の維持

- [ ] パラグアイ滞在 120 日以上を確保し、記録する
- [ ] **税務居住者証明書（Certificado de Residencia Fiscal）** を DNIT で取得
- [ ] パラグアイでの確定申告・納税
- [ ] 公共料金の請求・支払記録を12か月分保管
- [ ] パスポートの出入国スタンプを全ページコピーして保管
- [ ] 滞在日数カレンダーを搭乗券・宿泊記録で裏付けて作成
- [ ] 日本源泉所得がある場合は納税管理人経由で確定申告
- [ ] 書類は **5〜7年** 保管（アポスティーユ＋翻訳を付したもの）
