# 販売ページ文案 — 就労継続支援 経営KPIシート（v1）

## タイトル
**就労継続支援の「数字の見える化」Excel — 利用率・平均工賃・工賃の原資・期限を1枚で管理**

## 価格
14,800円（税込）／ 発売記念 9,800円（先着30件）

## 本文

事業所の数字、毎月バラバラの表で管理していませんか。

- 利用率が下がっていたことに、月末の請求まで気づかない
- 工賃を払いすぎて、**工賃の原資（生産活動収入 − 経費）を超えていた**
- サービス管理責任者の更新研修の期限が、いつの間にか迫っていた
- 会議のたびに、前月の数字を探して資料を作り直している

このシートは、**複数の障害福祉事業所の経営を毎月支援してきた実務家**が、
現場で実際に使っている管理の型を、どの事業所でも使える形に作り直したものです。

### できること
1. **毎月の数字を1か所に入れるだけ**で、利用率・平均工賃月額（目安）・工賃の時給換算・原資に対する工賃の割合・問合せからの契約率を自動で計算
2. **要注意の項目が赤くなる** — 工賃が原資を超えた月、サービス管理責任者の欠員、目標未達、未収金、返戻
3. **ダッシュボード** — 月を選ぶだけで前月比較。会議資料・議事録にそのまま使える
4. **期限管理** — 指定更新、サービス管理責任者の研修、加算の届出、運営指導、36協定。期限の90日前から赤く表示（日数は変更可）

### こんな方に
- 就労継続支援A型・B型、就労移行支援の経営者・管理者
- 複数の事業所を運営していて、数字を横並びで見たい法人
- 運営指導（実地指導）の前に、慌てて数字を集めている方

### 仕様
- Excel（.xlsx）。Googleスプレッドシートでも動作します（マクロなし）
- シート: 使い方／ダッシュボード／設定／月次入力／自動計算／期限管理
- 平均工賃月額は、令和6年度報酬改定の「平均利用者数」を用いる算定方式に沿った**月次の目安**です
