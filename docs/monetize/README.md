## 販売先の比較

| | **note** | **Brain** | **Tips** |
|---|---|---|---|
| 手取り（1,000円・カード決済） | **約855円**（事務手数料5%＋利用料10%）＋振込手数料270円/回 | 約88%（手数料 約12%）※公式で要確認 | 公式で要確認 |
| 集客力 | ◎ 検索・おすすめ表示に乗りやすい。一般読者が多い | ○ 「稼ぐ系」の読者が多い | △ |
| 紹介報酬（アフィリエイト）機能 | △ 限定的 | ◎ 購入者が紹介すると報酬が出る仕組みが標準 | ○ |
| 信頼感・ブランド | ◎ | △「情報商材」の印象がある | △ |
| 向いている商品 | 体験談・実務ノウハウ | 副業・稼ぎ方ノウハウ | 同上 |

**結論: 第1弾は note。** テーマ（海外移住・税務）は「信頼感」が売上を決めるので、情報商材の印象がある販売先は避けます。
第2弾「SNS運用代行をAIで回す方法」は Brain の紹介報酬の仕組みと相性が良いので、そちらで検討します。

## 守るべきルール（ここだけは必ず）

| リスク | 内容 | 対策 |
|---|---|---|
| **税理士法** | 個別の税務相談を有料で受けるのは、税理士の資格がないとできない | 「一般情報の記事」に限定。**個別の相談は受けない**。記事末尾に注意書き |
| **ステマ規制（景品表示法）** | 紹介リンクを貼る投稿・記事は、広告であることの表示が必要（2023年10月〜） | 紹介リンクには「PR」「広告」と明記 |
| **身元の露出** | 氏名・会社名・口座・住所が特定されると、税務・防犯の両面でリスク | 匿名アカウント。体験は一般化して書く |
| **Xの凍結** | 自動の返信・いいねを大量に行うと凍結される | 自動化は「予約投稿」のみ。返信は自動化しない |
