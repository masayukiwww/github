# 収益化の主軸（v1・2026-09-30）

## 結論

**主軸は「障害福祉事業所向けの経営ツールと解説を、ネットで自動販売すること」。**
NWB のコンサルで毎月使っている KPI 管理の型を、**誰でも使える商品に作り直して**売る。
人とのやり取りはしない。営業もしない。

前回の本命だった「海外移住の税金の有料記事」は、**第2の柱**に下げる。

## なぜこれが主軸なのか

| 観点 | 障害福祉の経営ツール | 海外移住の税金記事 |
|---|---|---|
| 嶋田さんの強み | ◎ **約10社を毎月見ている現役のプロ** | ○ 実体験はあるが、手続きはまだ途中 |
| 買う人の数 | ◎ 就労継続支援だけでも全国に1万か所以上 | △ 移住を考える経営者は少数 |
| 払う理由 | ◎ 実地指導での返還・減算を避けたい、利用率と工賃を上げたい＝**お金に直結** | ○ 税金の失敗を避けたい |
| 経費で買えるか | ◎ 事業所の経費で買える → 高い価格でも売れる | △ 個人の財布から払う |
| 繰り返し売れるか | ◎ 報酬改定・制度変更のたびに更新版が必要 | △ 一度読めば終わり |
| 法律の制約 | ○ 一般的な情報とツールならOK | △ 税理士法の制約が強い |

### 株・FX・暗号資産について

Bybit、Coincheck、サクソバンク、みずほ証券の口座をお持ちです。ただし、以下の2点に注意が必要です。
- **Bybit は日本の金融庁に登録されていない業者**です（過去に金融庁から警告を受けています）。
  大きな資金を置くのは避ける
- 日本の証券会社・暗号資産の取引所は、**非居住者になると、新しい取引や口座の継続が制限される**ことが多い。
  住所の届出とも関係するので、主軸の収益化とは切り離して、別途整理する
