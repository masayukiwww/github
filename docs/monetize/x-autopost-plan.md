# X 自動投稿の設計（v0.1）

## 目的

匿名アカウントで「海外移住 × 経営者 × 税金」の実務情報を毎日発信し、
note の有料記事へ誘導する。**人とのやり取りはしない。**

## アカウント設計

| 項目 | 案 |
|---|---|
| 表示名 | 移住する社長の税金メモ（仮） |
| プロフィール | 日本で法人経営 → 住民票を抜いて南米移住中。「海外に住めば税金ゼロ」の誤解と、正しい手順を実体験で発信。個別の税務相談は受けていません。 |
| 固定投稿 | note 第1弾の紹介（無料部分の要点＋リンク） |
| 顔・本名・会社名 | 出さない |

## 運用ルール

- 投稿: **1日2本**（日本時間の 7:30 と 21:00）。予約投稿で自動化
- 構成（1週間14本）: 知識 8本 ／ 体験 4本 ／ note 誘導 2本
- 返信・いいね・フォローの自動化は**しない**（凍結対策）
- 紹介リンクを含む投稿には「PR」と明記
- 数字や法律を書くときは、根拠となる条文・公式ページを把握したうえで書く

## 自動化の仕組み（案）

1. 私が **2週間分（28本）** をまとめて作成し、スプレッドシートに並べる
2. ★ 嶋田さん: 一覧をざっと見て、NGの投稿に印をつける（10分）
3. 予約投稿ツールで自動投稿
   - 第一候補: X 標準の予約投稿（無料・凍結リスクが最も低い）
   - 既存の自動化の仕組み（X reply 20 等）を流用する場合は、返信ではなく投稿のみに使う
4. 2週間ごとに、反応の良かった投稿の型を分析して次の28本に反映

## 投稿例（最初の10本）

1. 「住民票を抜けば非居住者」は誤解です。日本の法律に183日ルールはありません。判断基準は"生活の本拠"。自宅・家族・仕事・滞在日数の総合判断です。
2. 海外に住んでも、日本の会社から受け取る役員報酬は日本で20.42%源泉徴収されます。どこで働いても"日本の所得"扱い。移住前に報酬設計を見直すべき理由です。
3. 海外の銀行口座の情報は、"登録住所の国"の税務署に自動で報告されます（CRS）。住民票を抜いても、銀行の住所が日本のままなら日本に報告されます。
4. ただし、移住先の納税者番号がないうちは、銀行の住所変更は通りません。焦って自己宣誓書に書き込むのは逆効果。順番は「在留許可 → 納税者番号 → 銀行」。
5. 「国外所得は非課税」の国でも、国外法人からの配当や海外口座の利息を"国内所得とみなす"規定があることがあります。パラグアイもそうです。セミナーでは言われません。
6. 移住の証拠は"後から集められない"ものが多い。出入国スタンプ、毎月の電気・水道の請求書。移住初月から毎月フォルダに保存する仕組みを作るのが一番の節税対策です。
7. 税率の低い国の法人を、日本に住んでいるうちに作ると、日本で合算課税されることがあります（タックスヘイブン対策税制）。海外法人は"いつ作るか"で結果が変わります。
8. 【体験】海外の銀行に住所変更を頼んだら、書類を送ったのに反映されていませんでした。銀行は"納税者番号"で住所の妥当性を確認します。書類より先に番号です。
9. 家族が日本に残ったままの単身移住は、非居住者の判定でかなり不利になります。「家族の同行をどうするか」は、税金の面では最初に決めるべき論点です。
10. 【PR】住民票を抜いた経営者が最初にぶつかる"税金の壁"を、役員報酬・配当・海外口座の順にまとめました。「ゼロ」を狙わず、確実に下げる設計です。→ （noteのリンク）
